    10. Beispiel 08 – Tags für Listen

    Das folgende Beispiel befasst sich mit den Tags, die Listen anzeigen. Wir sind ihnen bereits im vorherigen Beispiel begegnet: die Dropdown-Liste, die Kontrollkästchen und die Optionsfelder. Das Testformular sieht wie folgt aus:

    10.1. Das NetBeans-Projekt

    Das NetBeans-Projekt sieht wie folgt aus:

    • wobei [1] die Aktion und [2] die zugehörige Ansicht ist.

    Die Datei [example/example.xml] konfiguriert die Anwendung:

    
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE struts PUBLIC
        "-//Apache Software Foundation//DTD Struts Configuration 2.0//EN"
        "http://struts.apache.org/dtds/struts-2.0.dtd">

<struts>
  <package name="example" namespace="/example" extends="struts-default">
    <action name="Form" class="example.Form">
      <result name="success">/example/Form.jsp</result>
    </action>
  </package>
</struts>

    Die Zeilen 8–9 zeigen, dass ein Aufruf der URL [/example/Form.action] die Ansicht [/example/Form.jsp] generiert. Die Aktion [Form] ist daher dafür zuständig, das Modell der Ansicht [Form.jsp] zu erstellen.

    Sehen wir uns die verschiedenen Eingabe-Tags des Formulars an:

    • Zeile 27: das Tag <s:select>: 
    
      <s:select name="select1" list="{'vert','jaune','rouge'}" size="1" key="Form.select1"/>

    Dieses Tag generiert den folgenden HTML-Code:

    1
2
3
4
5
    <select name="select1" size="1" id="Form_select1">
    <option value="vert">vert</option>
    <option value="jaune" selected="selected">jaune</option>
    <option value="rouge">rouge</option>
</select>

    Der Wert des Attributs list ist ein Array von Zeichenfolgen, das zur Generierung der Werte und Bezeichnungen der Optionen verwendet wird. Die zugehörige Vorlage ist das Feld select1 der folgenden Aktion [Form]:

    
  private String select1 = "jaune";

    Dieses Feld ist sowohl beim Lesen als auch beim Schreiben mit dem Tag „select1“ verknüpft. Beim Schreiben wird der Wert der ausgewählten Option in das Feld „select1“ eingefügt. Beim Lesen dient der Wert des Feldes „select1“ dazu, die ausgewählte Option zu bestimmen. Hier dient der Wert jaune des Feldes select1 dazu, die Option des Tags select1 auszuwählen, die den Wert „gelb“ hat. Deshalb ist in Zeile 3 die Option ausgewählt.

    • Zeile 28 
    
<s:select name="select2" list="{'vert','jaune','rouge'}" size="3" key="Form.select2" multiple="true"/>

    Es gibt keinen grundlegenden Unterschied zum Tag in Zeile 27, außer dass hier eine Mehrfachauswahl vorliegt. Der übermittelte Wert ist daher ein Array von Werten, nämlich die der ausgewählten Optionen. Das Feld select2 der mit dem Formular verknüpften Aktion lautet wie folgt:

    
  private String[] select2 = new String[]{"vert", "rouge"};

    Es handelt sich tatsächlich um ein Array. Sein Anfangswert dient dazu, die Optionen auszuwählen, deren Werte im Array enthalten sind.

    • Zeile 29 
    
      <s:select name="select3" list="#{'01':'vert(01)','02':'jaune(02)','03':'rouge(03)','04':'blanc(04)','05':'noir(05)'}" size="3" key="Form.select3" multiple="true"/>

    Hier ist der Wert des Attributs list ein Wörterbuch, dessen Schlüssel als Werte für die Optionen dienen und dessen zugehörige Werte als Bezeichnungen für die Optionen dienen. Der generierte HTML-Code lautet wie folgt:

    1

    <option value="01" selected="selected">vert(01)</option>
    <option value="02">jaune(02)</option>
    <option value="03" selected="selected">rouge(03)</option>
    <option value="04">blanc(04)</option>
    <option value="05">noir(05)</option>
</select>

    Das zugehörige Feld in der Aktion lautet wie folgt:

    
  private String[] select3 = new String[]{"01", "03"};

    Es handelt sich erneut um ein Wertearray, da das zugehörige Tag ein Mehrfachauswahlfeld ist. Die Anfangswerte des Arrays erklären, warum die Optionen in den Zeilen 2 und 4 zunächst ausgewählt sind.

    • Zeile 30 
    
      <s:select name="select4" list="dico" size="3" key="Form.select4" multiple="true"/>

    Hier werden die Optionen der Liste vom View-Template bereitgestellt, das hier Teil der Aktion [Form] ist:

    
private HashMap<String, String> dico = new HashMap<String, String>();

    Die Schlüssel des Dictionaries dico sind die Werte der Optionen. Die Werte des Dictionaries dico sind die Bezeichnungen der Optionen. Das Feld select4 der Aktion lautet wie folgt:

    
  private String[] select4 = new String[]{"1", "3"};

    Es handelt sich um ein Wertarray, das die vom Tag select4 übermittelten Werte aufnimmt.

    • Zeile 31 
    
<s:select name="select5" list="couleurs" listKey="id" listValue="nom" size="3" key="Form.select5" multiple="true" />

    Die Liste der Optionen wird durch das Feld couleurs generiert, das durch das Attribut list definiert ist. Das Feld couleurs der Aktion [Form] ist wie folgt definiert:

    
private Couleur[] couleurs;

    Die Klasse [Couleur] ist wie folgt definiert:

    
package example;

public class Couleur {

  // Felder
  private String id;
  private String nom;

  // Konstruktor
  public Couleur(){
  }

  // Getter und Setter
...  
}

    Sie verfügt über zwei Felder mit den Namen id und nom. Im Tag select5 gilt: listKey="id" listValue="nom". Das bedeutet, dass das Feld id als Wert für eine Option und das Feld nom als Bezeichnung dient. Es sei daran erinnert, dass die Werte der Optionen gebucht werden. Sie werden im folgenden Feld select5 gebucht:

    
  private String[] select5 = new String[]{"1", "3"};
    • Zeile 32 
    
<s:checkboxlist name="checkboxlist1" list="#{'01':'vert(01)','02':'jaune(02)','03':'rouge(03)','04':'blanc(04)','05':'noir(05)'}" key="Form.checkboxlist1"/>

    10.4. Die Aktion [Form]

    Bei der Erläuterung der Ansicht [Form.jsp] haben wir die Felder der zugehörigen Aktion [Form] vorgestellt. Der Code der Aktion [Form] lautet wie folgt:

    
package example;

import com.opensymphony.xwork2.ActionSupport;
import java.util.HashMap;

public class Form extends ActionSupport {

  // Formularfelder
  private String select1 = "jaune";
  private String[] select2 = new String[]{"vert", "rouge"};
  private String[] select3 = new String[]{"01", "03"};
  private String[] select4 = new String[]{"1", "3"};
  private String[] select5 = new String[]{"1", "3"};
  private HashMap<String, String> dico = new HashMap<String, String>();
  private Couleur[] couleurs;
  private String[] checkboxlist1 = new String[]{"01", "03"};
  private String[] checkboxlist2 = new String[]{"1", "3"};
  private String[] checkboxlist3 = new String[]{"1", "3"};
  private String radio1="01";
  private String radio2="1";
  private String radio3="1";

  private String submitText;

  // Konstruktor ohne Parameter
  public Form() {
    // Initialisierung des Farbwörterbuchs
    dico.put("1", "vert(1)");
    dico.put("2", "jaune(2)");
    dico.put("3", "bleu(3)");
    dico.put("4", "rouge(4)");
    dico.put("5", "blanc(5)");

    // Initialisierung des Arrays mit Farbobjekten
    couleurs = new Couleur[dico.size()];
    int i = 0;
    for (String key : dico.keySet()) {
      couleurs[i] = new Couleur();
      couleurs[i].setId(key);
      couleurs[i].setNom(dico.get(key));
      i++;
    }
  }

  // Ausgewählte Werte in Dropdown-Listen
  public String getSelect2SelectedValues() {
    return getArrayValue(select2);
  }

  public String getSelect3SelectedValues() {
    return getArrayValue(select3);
  }

  public String getSelect4SelectedValues() {
    return getArrayValue(select4);
  }

  public String getSelect5SelectedValues() {
    return getArrayValue(select5);
  }

  public String getCheckboxlist1SelectedValues() {
    return getArrayValue(checkboxlist1);
  }

  public String getCheckboxlist2SelectedValues() {
    return getArrayValue(checkboxlist2);
  }
  public String getCheckboxlist3SelectedValues() {
    return getArrayValue(checkboxlist3);
  }

  // Hilfsmethoden
  public String getArrayValue(String[] values) {
    String result = "";
    for (String value : values) {
      result += " " + value;
    }
    return result;
  }

  // Getter und Setter
   ...
}

    In dieser Aktion ist keine Methode execute zu finden. Daher wird die Methode execute der übergeordneten Klasse ActionSupport ausgeführt. Diese führt keine Aktion aus und gibt lediglich den Navigationsschlüssel SUCCESS zurück.
